Background

This repository contains the raw data and R code used to reproduce Figure 3 from Schaefer et al. (2000). Figure 3 shows 9-week moving averages of stream-water chemistry before and after Hurricane Hugo across forested watersheds in the Luquillo Experimental Forest in Puerto Rico.

This repository will be updated to reproduce the 9-week moving averages for the stream chemistry variables included in Figure 3:

Potassium Nitrate-N Magnesium Calcium Ammonium-N

The analysis focuses on the period from 1988 through 1994, allowing us to examine changes in stream chemistry before and after Hurricane Hugo.

Methods

Our analysis calculates 9-week moving averages of stream chemistry measurements and plots these averages over a time period from 1988 - 1994.

BQ1_new <- moving_average(BQ1)

BQ2_new <- moving_average(BQ2)

BQ3_new <- moving_average(BQ3)

PRM_new <- moving_average(PRM)


# Create Site_Name column for each dataframe
BQ1_new <- BQ1_new %>% mutate(Site_Name = "BQ1")

BQ2_new <- BQ2_new %>% mutate(Site_Name = "BQ2")

BQ3_new <- BQ3_new %>% mutate(Site_Name = "BQ3")

PRM_new <- PRM_new %>% mutate(Site_Name = "PRM")

# Combine all dfs into a new df
combined_dfs <- bind_rows(BQ1_new, BQ2_new, BQ3_new, PRM_new)

Results

Our results show the moving average of each chemistry variable over time (1988 - 2020).

plot_data <- combined_dfs %>%
  pivot_longer(
    cols = c(
      k_mgl,
      mg_mgl,
      ca_mgl,
      no3_mgl,
      nh4_mgl
    ),
    names_to = "Chemical",
    values_to = "Moving_Average"
  )


potassium_plot <- ggplot(
  data = plot_data %>% filter(Chemical == "k_mgl"),
  mapping = aes(
    x = window_start,
    y = Moving_Average,
    line_type = Site_Name
  )
) +
  geom_line() +
  labs(
    x = "Year",
    y = "Chemical"
  )
